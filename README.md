# Site Tacitus

Site estático do canal Tacitus (página inicial, política de privacidade e termos).
Para publicar no GitHub Pages: envie o conteúdo desta pasta `site/` para um repositório e ative o Pages na branch e na pasta correspondentes.
O arquivo `.nojekyll` já está incluído para servir os arquivos sem processamento do Jekyll.
A pasta `_previa/` é apenas para screenshots locais de conferência e não deve ser publicada.
Mantenha `index.html` na raiz como página inicial.
